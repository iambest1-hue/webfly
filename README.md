# ⚡ 飞雷神 - 视频弹出播放

一款浏览器扩展插件
> 飞雷神之术！一键将视频弹出到独立窗口播放，支持异屏全屏、弹幕保留、双向切换。

## ✨ 功能

### 📌 侧边常驻按钮

位于浏览器窗口右侧边缘的圆形按钮，始终可见：

- **弹出**：将当前整个标签页弹出到另一屏幕的独立窗口并最大化
- **返回**：将标签页移回原屏幕原窗口，恢复原位

### 🎬 视频浮层按钮

鼠标悬停在视频右 1/5 区域时浮现的小按钮：

- **弹出**：将当前标签页弹出到另一屏幕，浏览器窗口全屏（无地址栏边框），随后自动触发站点原生全屏，视频铺满整个屏幕
- **返回**：退出站点全屏，标签页移回原屏幕原窗口，网页完全恢复

### 🖥️ 站点原生全屏支持

视频浮层按钮的弹出模式会自动触发目标站点的全屏功能，因此**站点原有的播放器功能完全保留**：

| 功能 | 说明 |
|---|---|
| 弹幕 | B站弹幕、YouTube 实时字幕等正常显示 |
| 单击暂停/播放 | 站点自带的单击交互 |
| 双击退出全屏 | 站点原生的双击行为 |
| 鼠标滚轮调音量 | B站等站点的滚轮交互 |
| 全屏快捷键 | 键盘快捷键均正常响应 |
| 播放器控件 | 进度条、倍速、画质选择等 |

### 🖥️ 多显示器

- 自动检测当前显示器，将标签页弹出到**另一台显示器**上
- 只有一台显示器时弹出到同一屏幕

### 🌐 支持站点

| 站点 | 全屏触发方式 |
|---|---|
| Bilibili (B站) | 自动点击 `.bpx-player-ctrl-full` |
| YouTube | 自动点击 `.ytp-fullscreen-button` |
| video.js 播放器 | 自动点击 `.vjs-fullscreen-control` |
| DPlayer | 自动点击 `.dplayer-full-icon` |
| 其他 HTML5 视频站点 | 按 aria-label / title 匹配全屏按钮，未匹配时使用 Fullscreen API |

## 📦 安装

1. 打开 Edge 浏览器，进入 `edge://extensions`
2. 开启"开发人员模式"
3. 点击"加载解压缩的扩展"
4. 选择本文件夹

## 🎯 使用

### 📋 基本流程

```
打开含视频的网页
  ├── 点击右侧浮窗按钮  →  整个标签页弹出到另一屏（最大化）
  └── 鼠标悬停视频右 1/5 区域  →  浮现小按钮
       └── 点击小按钮  →  标签页弹出到另一屏（全屏）+ 站点原生全屏
                            ├── 视频铺满全屏，弹幕/控件正常
                            ├── 浮层按钮仍在（显示返回图标）
                            └── 点击浮层/侧边按钮  →  退出全屏，返回原窗口
```

### 🤔 两种按钮的区别

| | 侧边常驻按钮 | 视频浮层按钮 |
|---|---|---|
| 位置 | 浏览器右边缘，始终可见 | 视频右 1/5 区域，悬停浮现 |
| 弹出后 | 新窗口最大化，显示全部网页内容 | 新窗口全屏 + 站点全屏，仅显示视频 |
| 适用场景 | 需要完整网页的场合 | 只想看视频的场合 |

## 🔧 技术说明

- Manifest V3
- 权限：`storage`（状态存储）、`system.display`（多显示器检测）、`tabs`（标签页管理）
- 内容脚本注入所有页面（`all_frames: true`）
- 全屏采用窗口级全屏 `chrome.windows.update({state: 'fullscreen'})` + 站点原生 Fullscreen API 的组合方案
